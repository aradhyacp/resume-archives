# Resume Archives

The latest version of **Tejpal Aradhya CP's resume** is maintained at stable paths, while previous versions are preserved in the archive directories.

## Latest Resume

**Current source:** [main.tex](./main.tex)

[View or download the latest resume](./Tejpal_Aradhya_CP.pdf)

## Archive

Each resume update preserves the previous version:

- [archives/latex/](./archives/latex/) — historical LaTeX source files
- [archives/pdf/](./archives/pdf/) — historical compiled PDF files

Matching archive filenames use the same date-based prefix in both directories.

## Repository Structure

```text
main.tex                 latest editable resume source
Tejpal_Aradhya_CP.pdf    latest compiled resume
archives/latex/          historical .tex files
archives/pdf/            historical .pdf files
```

The README is maintained automatically by GitHub Actions whenever `main.tex` changes.
